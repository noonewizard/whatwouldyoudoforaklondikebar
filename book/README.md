## Standing rules

1. **Parallel is not descent.** Resemblance requires a documented route before it
   becomes influence.
2. **Never fabricate.** No invented quotations, citations, page numbers, manuscripts,
   rituals, organisations or consensus. Unverified material carries
   `[SOURCE VERIFICATION REQUIRED]` until closed or cut.
3. **Name the scholar.** Never "scholars agree." Never "historians have proven."
4. **Keep the five claim-types separate** — historical, phenomenological,
   psychological, sociological, metaphysical. The narrator never asserts the fifth.
5. **Respect fraternal obligation.** No private ritual material is reproduced or
   invented; published historical sources only; jurisdictional variation stated.
