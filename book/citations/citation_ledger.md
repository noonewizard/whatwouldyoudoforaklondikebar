# CITATION LEDGER

One row per substantive factual claim in the manuscript. Populated during drafting.
A chapter is not complete until every claim in it appears here.

## Columns

| Field | Meaning |
|---|---|
| Ch | Chapter number |
| Claim | The assertion, as it appears in the text |
| Source | Bibliography entry no. + short form |
| Page | Exact page(s) in the stated edition |
| Edition | The edition actually consulted |
| Date | Publication date of that edition |
| Class | A (primary) / B (scholarly) / C (critical edn.) / D (popular) |
| Conf | High / Medium / Low |
| Competing | Rival interpretation, if any, and who holds it |
