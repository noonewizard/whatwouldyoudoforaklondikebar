# INDEX FRAMEWORK

A working framework for the professional indexer, not a finished index — page numbers cannot
be assigned before typesetting. What follows is the structure: the entries the book requires,
the subheadings each needs, and the cross-references that carry the argument.

**Three principles govern this index.**

1. **Distinctions the book insists on must survive indexing.** Kabbalah, Cabala and Qabalah
   get three entries, not one with variants. Esotericism and occultism get two. Hermetism and
   Hermeticism get two. An index that merges them undoes a hundred pages of argument.
2. **Claims the book rejects are indexed under their own names**, with the location of the
   rejection. A reader looking up "Templar descent" should find it and find the answer.
3. **Methodological terms are indexed as fully as historical ones**, because the method is
   half the book.

## F — DISTINCTIONS REQUIRING SEPARATE ENTRIES

The indexer is asked to treat these as non-negotiable. Each pair or triple is a distinction
the book spends chapters establishing, and a merged entry destroys it.

| Keep apart | Not |
|---|---|
| Kabbalah / Cabala / Qabalah | "Kabbalah, *var.*" |
| Esotericism / Occultism | "Esotericism, *see* Occultism" |
| Hermetism / Hermeticism | one entry |
| Magic, Types A–E | "Magic" |
| Masonic bodies / bodies whose members were Masons / bodies borrowing Masonic form | "Masonic organizations" |
| Historical claim / psychological claim / metaphysical claim | one entry per topic |
| Availability (of a text) / transmission | one entry |

## NOTE ON LENGTH

A book of this length and density supports an index of roughly 12–16 printed pages.
Compressing it further would mean sacrificing either section D or section F, and section F is
the one that makes the book usable as a reference. If space is constrained, reduce section A
to principal discussions only.
