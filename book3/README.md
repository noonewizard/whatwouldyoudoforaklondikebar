## THE COMPUTATIONAL RESULT THAT ORGANISES THE BOOK

Everything in `research/computational_verification/` is re-runnable.

The Atbash sequence is kept in **three versions**, deliberately, because the
sequence is the lesson:

- **v1** — a confounded control (BAPHOMET searched 216 spellings, controls 12–72)
  presented as a passed one. **A failed control that looked like a result.**
- **v2** — skeletons matched. Controls 0/777; Baphomet 1/216; random base rate
  ~1 in 10⁶. **On this showing the claim appears to survive**, and an honest analyst
  would have to say so.
- **v3** — where did the target list come from? I wrote it, knowing the answer.
  *Sophia* is Greek, defectively transliterated, and on the list only because the
  claim put it there. Remove it and Baphomet returns **0 hits, like every control.**

**The transformation is real** — בפומת → שופיא reproduces exactly. What carries no
weight is the interpretation, because the success criterion was written by someone
who already had the answer.
