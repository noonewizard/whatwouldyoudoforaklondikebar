# APPENDIX H
## Evidence Classification

Every substantive claim in this book carries an internal tag. Tags appear in the
body text only where they clarify rather than clutter.

---

## THE SCALE

| Tag | Level | Meaning |
|---|---|---|
| **E1** | Direct primary evidence | A period document says so, or a computation reproduces |
| **E2** | Strong scholarly evidence | Specialists converge from good evidence |
| **E3** | Reasonable interpretation | Consistent with the evidence; alternatives open |
| **E4** | Disputed | Competent scholars disagree |
| **E5** | Speculative | Chronologically possible; no transmission or corroboration |
| **E6** | Unsupported | Fails the tests; often chronologically impossible |

**Standing rule: no E5 or E6 claim appears as factual prose.** Where such claims are
discussed, the text names whose claim it is and what it fails. Every E3 is marked as
interpretation in the body, not merely in a note. E4 items are reported as disputes
with both sides attributed, never resolved by authorial preference.

## WHAT WOULD FALSIFY THE MAIN ARGUMENT

Stated in advance, as Chapter 42 requires of everyone else.

**Claim 4 fails** if a pre-1720s document is produced in which a Masonic word is
used and subsequently reported lost.

**Claim 17 fails** if Masonic cipher material of concealment grade — keyed,
polyalphabetic, or frequency-suppressing — is produced from the period.

**Claim 18 fails** if an early source states a rule for reconstituting a word after
"halving," and if that rule is stable across sources.

**Claims 22 and 24 fail** if pre-1750 Masonic sources are produced using
Kabbalistic vocabulary structurally.

**Claim 23 resolves** if archival evidence connects the Royal Arch's compilers to
Christian-Hebraist reading — a library list, a subscription, a correspondence, a
marginal note.

**Claims 27–30 fail** if a documented transmission route is established with verbal
dependence, not thematic resemblance.

None of these has occurred. All of them could.

## SOURCE QUALITY HIERARCHY

| Level | Description |
|---|---|
| **A** | Primary historical evidence |
| **B** | Peer-reviewed scholarship |
| **C** | University press monographs |
| **D** | Recognized scholarly reference works |
| **E** | Established specialist publications |
| **F** | Popular sources, used **only** to document popular belief |

**Level F is never used to establish historical fact.** Sources in that category are
segregated in the bibliography and marked.
