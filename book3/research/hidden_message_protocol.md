# HIDDEN-MESSAGE RESEARCH PROTOCOL

Per §XXVII. This is the book's practical contribution (§LIII) and Appendix I.

It applies to any claim that a text, symbol, building or name conceals a message.
It is not a device for rejecting such claims. Two of the worked examples below
**pass**, and the protocol's value depends on its being able to say so.

---

## THE TEN TESTS

**1 — PROVENANCE.** Where did the text come from? Who held it, when, and who
vouches for the chain? A decipherment of a document of unknown origin decodes
nothing, because there is no author to have encoded it.

**2 — DATING.** When was the alleged encoding performed? Establish the date of the
*artefact*, not of the tradition it claims. A claim requiring an eighteenth-century
author to encode a nineteenth-century doctrine is dead on arrival.

**3 — ENCODING RULE.** Is the cipher independently documented as a real system,
used by real people, described somewhere other than in the claim itself? A rule
reconstructed by the claimant is not a rule.

**4 — PRECOMMITMENT.** Was the method specified before the result was seen?
**This is the decisive test and the one almost every claim fails.** Includes the
target criterion: what would have counted as a meaningful output, fixed in advance?

**5 — CONTROLS.** Does the same method, run on matched material that cannot contain
the message, produce comparable results? The controls must match in *search-space
size*, not merely in subject. (See the v1 error in
`research/computational_verification/README.md`.)

**6 — BASE RATE.** How often does a meaningful output arise by chance, given the
size of the search space and the generosity of the acceptance criterion? State
both numbers.

**7 — REPLICATION.** Can an independent researcher, given only the stated method,
reproduce the result without further guidance? If the claimant must intervene, the
method is underspecified.

**8 — HISTORICAL PLAUSIBILITY.** Could the alleged author have used this method?
Did they have the language, the technique, the materials, the motive? Would they
have chosen a system already obsolete?

**9 — ALTERNATIVE EXPLANATIONS.** Is there a simpler account — coincidence, a
common source, convergent design, a scribal convention, a later interpolation?

**10 — INTENTIONALITY.** Is there evidence the pattern was *put there*? Not that it
is present and not that it is meaningful, but that someone placed it. This is the
§XLV distinction between meaning and intention, and it is the only test that can
turn an observation into a finding.

**Scoring.** A claim failing 4 or 5 carries no evidential weight regardless of how
striking the output is. A claim failing 2 or 8 is dead. A claim failing only 9 may
be true and is not yet demonstrated.

## WORKED EXAMPLE 1 — THE BIBLE CODE — **FAILS**

| Test | Result |
|---|---|
| 1 Provenance | Pass — Masoretic text, well established |
| 2 Dating | Pass in form; but the claim requires foreknowledge of modern events |
| 3 Encoding rule | Fail — equidistant letter sequences are not an attested ancient practice |
| 4 Precommitment | **Fail** — skip distances and target words chosen after inspection |
| 5 Controls | **Fail decisively** — McKay, Bar-Natan, Bar-Hillel & Kalai found the same "predictions" in *Moby-Dick* |
| 6 Base rate | Fail — search space effectively unbounded |
| 7 Replication | Fail — results do not survive independent protocol |
| 8 Plausibility | Fail |
| 9 Alternatives | Fail — chance suffices |
| 10 Intentionality | Fail — no evidence of placement |

Reference: *Statistical Science* 14, no. 2 (1999): 150–73. **This is the model the
whole protocol imitates.**

## WORKED EXAMPLE 2 — ATBASH / BAPHOMET → SOPHIA — **FAILS, BUT NOT WHERE EXPECTED**

| Test | Result |
|---|---|
| 1 Provenance | **Fail** — the Templar depositions are inquisitorial testimony under torture; "Baphomet" appears in wildly variant forms |
| 2 Dating | Fail — the claim is Schonfield's, 1984 |
| 3 Encoding rule | **Pass** — Atbash is genuinely attested (Jer 25:26; 51:41; 51:1) |
| 4 Precommitment | **Fail** — the target lexicon was built knowing the answer |
| 5 Controls | **Fail** — matched controls return 0; so does Baphomet once *Sophia* is removed from the target list |
| 6 Base rate | Fail — 216 admissible spellings against a 44-item target list |
| 7 Replication | **Pass** — the transformation itself reproduces exactly: בפומת → שופיא |
| 8 Plausibility | Fail — no evidence the Templars used Atbash, or Hebrew |
| 9 Alternatives | Fail — coincidence, plus a variant spelling chosen to suit |
| 10 Intentionality | Fail |

**Note what passes.** Tests 3 and 7 pass cleanly: the technique is real and the
arithmetic is exact. This is why the claim is persuasive, and why the protocol has
to go further than "it's nonsense." It is not nonsense. It is an accurate
computation whose interpretation was fixed after the result.

**And note the Masonic irrelevance:** even if it held, it would be a claim about
the Templars, and the Templar→Masonry chain fails independently (Book I).

## WORKED EXAMPLE 3 — THE PIGPEN GRAVESTONES — **PASSES**

| Test | Result |
|---|---|
| 1 Provenance | Pass — physical monuments, located, dated, photographable |
| 2 Dating | Pass — 18th–19th c., contemporaneous with the practice |
| 3 Encoding rule | Pass — the grid is documented independently in Masonic and cryptographic literature |
| 4 Precommitment | Pass — the alphabet is fixed and public *before* any inscription is read |
| 5 Controls | Pass — applied to non-Masonic monuments it yields nothing |
| 6 Base rate | Pass — the output is continuous English text, not a single lucky word |
| 7 Replication | Pass — anyone with the grid reads the same inscription |
| 8 Plausibility | Pass — Masons demonstrably used it |
| 9 Alternatives | Pass — no simpler account of a legible sentence |
| 10 Intentionality | Pass — somebody carved it |

**Ten for ten.** This is what a demonstrated historical encoding looks like, and
the contrast with Examples 1 and 2 is the point. What it encodes, however, is a
name and a date — not doctrine. **A genuine cipher, genuinely used, carrying
nothing secret.**

## WORKED EXAMPLE 4 — ENOCHIAN — **PASSES, WITH THE CATEGORY CORRECTED**

Dee and Kelley's angelic language (1582–89) passes on provenance, dating, rule,
replication and intentionality: the manuscripts survive, the sessions are dated,
the tables are reproducible, and Dee wrote it all down.

**But it is not a recovered language; it is a produced one.** It is the control
case for the whole book — a fully documented instance of a sacred language coming
into existence in recorded time, with named authors and a diary. Anyone proposing
that a sacred language was *recovered* should be asked why the one case we can
watch in full detail was *made*.

## THE MEANING / INTENTION DISTINCTION

Per §XLV, restated for use throughout:

- **A symbol can acquire meaning its maker never intended.** Legitimate; a fact
  about reception; not evidence about origin.
- **A reader can discover a real interpretation the designer did not place there.**
  Also legitimate, and not a discovery *about the designer*.
- **A coincidence can be meaningful and still be a coincidence.** Meaning is not
  scarce; intention is.
- **An intentionally encoded message requires evidence of intentional encoding** —
  which is Test 10, and which no amount of output can supply.
