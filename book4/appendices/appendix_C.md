# APPENDIX C
## Chronology

Dates given as the sources give them; disputed dates are marked. Nothing in this
table should be read as resolving a dispute the book left open.

### The site and the buildings

| Date | Event |
|---|---|
| c. 14th c. BCE | Urusalim named in the Amarna correspondence |
| 10th c. BCE (traditional) | David's capture of the city; Solomon's building. **Scale and date disputed** (chs 2, 4) |
| 586 BCE | Babylonian destruction of the first Temple |
| 538 BCE onward | Return under Persian authority |
| c. 516 BCE | Second Temple completed |
| 2nd c. BCE | Seleucid desecration; Maccabean rededication |
| from c. 20 BCE | Herod's reconstruction and platform expansion |
| 70 CE | Roman destruction of the second Temple |
| 135 CE | Refoundation as Aelia Capitolina |
| 4th c. CE | Christian Jerusalem; the platform left in ruins |
| 638 | Muslim conquest |
| 691–92 | Dome of the Rock completed |
| 1099 / 1187 | Crusader conquest / Saladin's reconquest |
| 1535–42 | Ottoman city walls (Suleiman) |
| 1852–53 | Ottoman decrees underlying the Status Quo |
| 1967 | Present security and administrative arrangements begin (ch 63) |
