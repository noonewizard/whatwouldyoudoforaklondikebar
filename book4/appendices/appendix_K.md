# APPENDIX K
## The Ten-Test Hidden-Message Protocol

Established in Book III; applied unchanged in Part XV.

| # | Test | The question it asks |
|---|---|---|
| 1 | **Provenance** | Where does the text or measurement come from, in what form? |
| 2 | **Dating** | When was it fixed, relative to when the code was supposedly inserted? |
| 3 | **Encoding rule** | Is the rule stated precisely enough that another person produces the same output? |
| 4 | **Precommitment** | Was the target specified before the search? |
| 5 | **Controls** | Does the same method on comparable material with no claim attached produce comparable results? |
| 6 | **Base rate** | How often would this occur by chance? |
| 7 | **Replication** | Does it hold on independent material? |
| 8 | **Plausibility** | Was the technique available to the people said to have used it? |
| 9 | **Alternatives** | Is there a simpler explanation? |
| 10 | **Intentionality** | Is there evidence anyone meant to do it? |

### The rule extracted

**Most claims fail at test three.** If the interpreter has to reconstruct the rule,
and two interpreters reconstruct it differently, there is no cipher — there is a
text and several readers.

**Essentially all of them fail at test five.** A positive result that a matched
control reproduces at a comparable rate is not a positive result. It is a
description of the search.
