## What was found

### FUZZ-01 — integer overflow in the length bounds check

Found in under two minutes, on the first run of the first target.

Input, nine bytes: `7b ff ff ff ff ff ff ff ff` — CBOR major type 3 (text
string) with additional information 27, meaning an eight-byte length
follows, set to `u64::MAX`.

`Decoder::len_of` computed `self.pos + n` and compared it to the input
length. With `n = usize::MAX` that addition overflows: a panic under debug
assertions, a wrapped comparison without them — and a wrapped comparison
can pass.

The decoder runs on a network path, so a nine-byte message that panics or
wraps the bounds check is a denial-of-service defect. Recorded as FUZZ-01
in `security/findings.md`.

**Fixed** by comparing in `u64` against the remaining input rather than
computing `pos + n` at all. The regression test generalises the single
input libFuzzer found to all four length-carrying major types — byte
string, text string, array and map — because the same header shape reaches
the same helper from each.

## What this does and does not establish

**Establishes:** 31.3 million executions across six targets, with
AddressSanitizer and debug assertions on, produced no crash, no assertion
failure, no forged signature and no Merkle proof verifying against an
unrelated root.

**Does not establish** that the code is free of defects. Sixteen minutes
is a short campaign; the corpora were built from nothing rather than
seeded from the conformance vectors; and the two negative-property targets
(`envelope_verify`, `inclusion_proof_verify`) are unlikely to reach a
forgery by random search whatever the duration — their value is as a
tripwire, not as a search.

**The honest reading of the one finding:** a coverage-guided fuzzer found
in under two minutes a defect that property tests, 269 unit tests, a
second independent implementation and a formal model had all missed. That
is not a criticism of those; it is what coverage-guided fuzzing is for,
and it is the argument for running it continuously rather than once.
